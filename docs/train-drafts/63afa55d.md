# Detect same-module replacements that pin module selection

## What we want to improve

Detect a `go.mod` with a normal requirement on module `M` and an unversioned replacement of the form `replace M => M vTarget`. The old and new module paths must be identical and the replacement target must be a version, not a local path.

## Why this matters

An unversioned left side replaces every selected version of that module, regardless of semantic-version ordering. That can silently pin later direct or transitive upgrades to one snapshot. For an ordinary upgrade, requiring the target version directly expresses a minimum while preserving Go's module selection; a deliberate global override deserves explicit scrutiny.

## Examples

- `require example.com/pkg v1.1.0` plus `replace example.com/pkg => example.com/pkg v1.1.1-0.20240102123456-abcdef123456` globally pins the module instead of expressing the intended upgrade.
- `require example.org/tool v0.9.1` plus `replace example.org/tool => example.org/tool v0.9.2` overrides every version selected for that path.

## Keep it focused

- A local filesystem replacement such as `replace example.com/pkg => ../pkg` is a different mechanism and remains covered by the existing local-replace rule.
- A replacement to a different module path is a fork substitution and should not trigger this check.
- A version-specific left side such as `replace example.com/pkg v1.1.0 => example.com/pkg v1.1.1` only replaces one selected version and should remain quiet.
- A same-module replacement without a corresponding `require` in the same file lacks enough local evidence for this finding.

## Done when

- [ ] Flag `require M vRequired` with an unversioned `replace M => M vTarget`.
- [ ] Identify both versions and explain that the unversioned replacement overrides every selected version of `M`.
- [ ] Recommend removing the replacement and requiring the target directly for an upgrade, or documenting why a global override is necessary.
- [ ] Do not flag local replacements, different-module forks, version-specific left sides, or replacements without a matching requirement.
